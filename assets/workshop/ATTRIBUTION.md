# Workshop cover provenance

The current cover uses a generated industrial background and large bilingual title, composed with four original Probably Stolen resource icons at the author's request: printer_plastic, scrap_metal, electronic1 (common electronics), and ore1 (common ore), in one horizontal row.

Original game icon artwork remains with the game's rights holders and is not relicensed under this project's MIT license. Raw extracted sprites and game asset files are not separately distributed here or in the Mod package. The flattened promotional cover is retained as the requested publication asset. The composition script accepts local icon paths, with alpha cropping and integer nearest-neighbor placement to preserve the original silhouettes and colors.

The initial English-only and discarded crate-based bilingual covers are historical candidates. The active cover is cover-0.2.1-original-icons-zh-en.jpg. Background/title layer was made using the built-in imagegen tool. Final composition is a deterministic placement of original icons, as explicitly requested.

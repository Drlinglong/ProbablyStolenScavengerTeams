# 王尔德的拾荒者小队 0.2.0

在王尔德人脉的“基础”面板中找到“拾荒者”大类，四行依次为打印耗材、废金属、普通电子元件、小行星开采队（普通矿石），每行1→2→3级。

| 路线 | 标准难度各级基础服务费 |
| --- | --- |
| 打印耗材 | 200 / 300 / 450 |
| 废金属 | 200 / 300 / 450 |
| 电子元件（普通） | 250 / 350 / 500 |
| 小行星开采队 | 200 / 300 / 450 |

原版难度和人物价格修正继续生效。服务为逐级一次性购买，货款另付。

四类各自独立计时：购买次日首次上门，以后每隔3天。升级只提升该队货量，不增加重复低等级来客，不重置日期或首次特惠。

- 1级：6个对应原版材料＋2垃圾。
- 2级：2箱对应材料＋4垃圾。
- 3级：3箱对应材料＋6垃圾。
- 单买原价；每条路线各有一次首次来访整批五折，以后整批八五折，含全部剩余垃圾。拒收首次来访也不会留到下一次。
- 材料/箱子优先摆上柜台，垃圾最后摆；放不下的按原版销毁，读档不补回。请提前留足空间。
- 每箱占满3×3格，正常基础价为原版单件材料×6，继承其标签与分类。双击获得6个对应原版材料。矿石为可供熔炉使用的common_ore。
- 开箱前请确保有足够仓库空间。为支持失败回滚，当前容器、背包或后柜台需要能独立放下六件材料。箱子未购买、战斗中或空间不足时不会被消耗；无额外悬浮提示。

安装时保持整个文件夹结构，放入游戏Mods中，在游戏中启用并重启。更新无需新建存档；打印耗材旧升级ID、已购状态、日程及首次优惠键保持兼容。建议用测试局验收新三条路线。没有修改原版DLL，不需要网络或任意文件读写权限。

打印耗材完整流程已获用户实机验收，图标达到最低验收标准。0.2.0的新三条路线通过本地模拟宿主回归与编译，实际游戏中的供货、开箱和存读档仍待用户验证。

卸载前处理当前交易，并将新增箱子全部打开、材料放入玩家背包后正常保存退出。带新箱子的存档卸载行为未获实机验收。

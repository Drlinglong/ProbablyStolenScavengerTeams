# 0.1.1 人脉服务显示修复

2026-11-07。

用户实机确认测试资金在恩惠中可购买、到账99999且只能购买一次；拾荒者服务未显示。Player.log则显示两个Mod均在OnEnable调用AddNetworkUpgrade时抛出空引用。不能把测试资金购买生效误写为其启动初始化正常。

实际调用链为AddNetworkUpgrade → NetworkUpgrade.RegisterModUpgrade → PlayerStore.Instance → PlayerStore构造函数。原版单例会惰性创建实例，主菜单加载Mod时依赖未就绪。注册定义在抛错前已部分写入静态列表，因此测试资金的单项仍可能出现，但拾荒者三级注册在第一项中断，Mod被标记为初始化失败，图标资源也未被加载。这是加载失败，并非单纯分类位置不醒目。

修复将人脉服务注册推迟到OnGameLoadedEarly或OnNewGameStarted。Mod启动只绑定生命周期和物品注册钩子，让Mod加载和资源加载完成。新增“拾荒者”页签、“打印耗材”分组，保留三个升级ID、费用、原有存档键和所有供货规则。测试资金做相同注册时机修复，保留原有领取标记。

验证：新增启动依赖未就绪的回归，在旧生产代码上明确失败，修复后24项宿主回归通过。另调用当前游戏真实NetworkUpgradeLayout.Build，确认新页签、三格升级链及基础页签保留。测试资金独立宿主检查覆盖新开局/读档注册和重复领取防护。两包对当前游戏DLL编译通过。

状态：DONE_WITH_CONCERNS。以上未验证Unity画面，更新后需用户在游戏中确认“拾荒者”页签、图标和交易。未直接修改存档、启用记录或信任记录。旧版Mod目录在安装前单独备份，路径记入安装收据。

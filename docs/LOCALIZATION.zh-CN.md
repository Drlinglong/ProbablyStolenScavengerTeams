# 修改文案

已验收的0.2.0最初没有CSV，中文写在C#中。该版本已作为42729a2提交。0.2.1已把游戏内文案提取为原版ModLoader直接加载的CSV；1140c6e的文案和各级问候、c7554ea的分句对话均获用户实机确认。新增七语通过结构检查，用户已确认多国语言显示正常（未逐一列明所测试语言）。服务名称及各级说明已按用户提供的文案替换，并增加开通、升级后的专属问候。

## 编辑入口

主中文文件：content/Localization/zh.csv。英文及其他语言回退：content/Localization/en.csv。另有fr、de、ja、ru、es、pl.csv；七个非中文文件由Remis任务生成。均为UTF-8，每行key,value，两列。第一行是注释，不是需要翻译的内容。

主要键：

| 键 | 用途 |
| --- | --- |
| mod.name | 物品来源显示的Mod名 |
| category.scavengers | 人脉大类名称 |
| team.<route>.service_title | 服务标题 |
| team.<route>.service_description.1 / .2 / .3 | 各等级服务说明 |
| team.<route>.visitor_name | 来访者名称 |
| team.greeting / team.ore.greeting | 拾荒者共用普通问候 / 矿工普通问候 |
| team.intro.1 / .2 / .3 | 拾荒者开通、升级后首次来访问候 |
| team.ore.intro.1 / .2 / .3 | 矿工开通、升级后首次来访问候 |
| team.<route>.crate_name | 物品箱名称 |
| team.<route>.crate_description | 物品箱说明 |
| team.<route>.crate_flavor | 风味文本，可置空 |

route分别为printer、metal、electronic、ore。前三类共用拾荒者问候，矿工使用单独问候，各级服务说明仍可分别编辑。

只改第二列，保持第一列键不变。{0}是运行时参数，保持数量和编号；可在句中调整位置。服务标题的{0}为罗马数字I、II、III；箱子说明的{0}为开箱数量。服务说明和问候是完整文本，没有格式参数。

值含英文逗号时，按标准CSV用双引号包围；值中的双引号写为两个双引号。需要换行时写两个字符\n，不要把一个词条拆成多个物理行。不要让Excel另存为ANSI或改变UTF-8编码。

## 从编辑到游戏

build.ps1将Localization和贴图一起打包，并从zh.csv生成zh-Hans.csv、zh-CN.csv别名。只修改主源文件，不编辑生成的别名。

只改文字无需重新编译C#；把源CSV同步到Mod的Localization目录后，退出并重启游戏让原版重新加载。首次从0.2.0升级时须安装完整的0.2.1包以接入CSV读取；后续仅改文案可同步CSV及中文别名。安装文件哈希和备份位置由outputs中的安装记录保存。

原版清单的Mod显示名、简介属于manifest.xml元数据，仍在该文件中编辑；它们不是C#硬编码。英语日志和错误诊断也不是玩家剧情文案。运行时文案通过src/Text.cs调用原版ModHelper.GetLocalized，不自行读写任意文件。

显示文字与升级ID、物品ID和存档键分离。改变名称不会重置购买状态、供货日期、折扣、价格或开箱内容。读档后旧物品箱的名称、说明和风味文本也从当前语言CSV恢复。

开通或升级后的首次来访使用实际供货等级的专属问候，之后恢复普通问候。每条路线独立保存已问候等级及本批问候；同日读档保留本批对白。购买后在首访前连续升级，只播放最终等级问候。旧存档以已发生的供货等级作为历史进度，避免重新播放早已购买的等级问候；后续升级正常触发。不重置供货日期、剩余货物或首次批发优惠。

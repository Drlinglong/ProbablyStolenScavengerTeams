# 电话停送方案（待用户决定，未实现）

可接入王尔德已有通话菜单，在现有“浏览服务／结束通话”之外加入“管理拾荒队”，再按已购买路线选择暂停或恢复。不新增独立号码；不覆盖原版菜单选项。

建议规则：

- 每支队伍独立暂停，服务等级和购买状态保留。
- 暂停当天记为D，D+3起允许再次打电话恢复；按游戏日期计算，不用现实时间。
- 恢复后次日重新来访，此后每隔三天；暂停期间不积累、不补发货物。
- 暂停、恢复及暂停期间升级，均不刷新首次批发特惠，不额外收费。
- 已经到店的交易不强行撤回；当天尚在排队的客人是否取消，需要在实现前明确并测试，不能只改下一次日期却留下排队客人。
- 状态写入Mod自己的每路存档，读档后保留冷却；多语言文字仍走CSV，电话选项使用原版对话和选择接口。

接口依据：PhoneClientList.DialogFuncs["Wild"]负责王尔德电话，PhoneDialogList.PhoneWild创建原版选择页。实现时需保留原委托／选项，避免与其他电话Mod互相覆盖，并在停用时只撤销自己仍持有的包装。

当前任务只实现空酒瓶路线；本文件不代表已实现电话暂停，也不自动把用户“在考虑”的想法变为发布功能。

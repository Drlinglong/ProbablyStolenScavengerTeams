## 服务及兼容

王尔德人脉基础面板中保持一个“拾荒者”大类，四行顺序打印耗材、废金属、普通电子元件、矿石，各行1→2→3级。电子元件基础服务费250／350／500，其余路线200／300／450，原版难度和人物修正继续生效。

四类各自保存等级、到期日、当批货单、首次优惠及不可再提供的库存位。购买次日首访，之后每隔三天；升级不重置日程或特惠。首访批发五折，以后八五折，单买原价。每次先材料/箱子后垃圾，原版溢出销毁，读档不补回被销毁或已购买的货物。四条路线同时到期则追加四位不同供应商，不占原版随机顾客数量。

各路线1级6材料＋2垃圾，2级2箱＋4垃圾，3级3箱＋6垃圾。箱子均3×3实心占格，正常基础价为对应单件材料×6，继承原始标签及分类。当前原版基础箱价分别72／60／198／90，实际报价仍受原版机制影响。双击得到6件对应原版材料：printer_plastic、scrap_metal、common_electronic、common_ore。

箱子不继承散装材料的单件修理/升级目标动作，避免把一整箱当一件材料消耗；先开箱后按原版使用散件。开箱所有权、战斗限制及空间不足回滚沿用原流程。

打印耗材旧升级ID、客户ID、物品ID及printer.delivery.v1状态键保持原值，所有新路线有独立ID。新开局及加载后注册服务，启动阶段不读取惰性PlayerStore单例。
